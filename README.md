# STM32WB_Bluetooth_PCB
This project is a PCB built around an STM32WB for RF Bluetooth connection.

## Components
- STM32WB
- Crystal Oscillators:
    - HSE 32MHz 
    - LSE 32.768KHz
- 3.3V LDO
- USB C 2.0 + ESD protection
- Bluetooth RF connection via UFL connector + Filtering
- SWD Tag connect
- UART Connection

## Board Setup
The board is 4 layers witht he following stack-up:

Layer: 1	SIGNAL

Layer: 2	GND

Layer: 3	GND

Layer: 4	SIGNAL
